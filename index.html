// Bounded BFS Depth-2 Recommendation Logic
while (!queue_is_empty(q)) {
  int u = queue_dequeue(q);
  if (dist[u] >= 2) continue;
  for (neighbor : adj[u]) {
    if (dist[neighbor] == -1) {
      dist[neighbor] = dist[u] + 1;
      queue_enqueue(q, neighbor);
    }
  }
}

DSA Viva Quick Reference

BFS explores vertices level-by-level (by shortest path distance). This guarantees discovering all friends-of-friends at distance 2 before deeper nodes.
Social graphs are sparse (|E| << |V|²). Adjacency list uses O(V + E) space vs O(V²) for matrices, and allows O(degree) neighbor traversal.
djb2 uses hash * 33 + char with initial prime 5381. It provides uniform bit distribution and O(1) average lookup for usernames.
